# NexaCore IT

Modern and responsive IT company website built as a front-end portfolio project.

## 📌 About the Project

NexaCore IT is a modern business website designed for an IT services company.

The project focuses on:

* Clean and modern UI
* Responsive design
* User-friendly navigation
* Interactive JavaScript features
* Mobile-friendly layout
* Professional presentation of IT services

> This is a demo portfolio project created to demonstrate front-end web development skills.

## 🚀 Features

* Responsive navigation menu
* Hero section
* About section
* IT services section
* Why Choose Us section
* Projects showcase
* Client testimonials
* FAQ section
* Contact form validation
* Scroll reveal animations
* Responsive design for desktop, tablet, and mobile
* Dynamic copyright year

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## 💻 How to Run

No installation or backend is required.

Simply open:

```text
index.html
```

in a modern web browser.

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

## ⚠️ Demo Notice

This project is for portfolio demonstration purposes.

The contact form is a front-end demo and does not send real emails or store messages in a database.

Testimonials, projects, and company information are demo content.
